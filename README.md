# carthing-ha-image

Build-only mirror of the Car Thing configuration from Wessel's private home-assistant repo (`carthing/nixos/flake.nix`).
[nixos-superbird](https://github.com/JoeyEamigh/nixos-superbird) image for a Spotify Car Thing used as a wireless
Home Assistant dashboard: Bluetooth PAN to a Raspberry Pi + Chromium kiosk. Built natively on GitHub's arm64 runner.

Contains no secrets (only public SSH keys and a Bluetooth address). Edit in the private repo, then copy here.
